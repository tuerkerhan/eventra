2. CRM Pipeline State Machine

Eventra Pro'nun kalbi olan CRM Pipeline akışı. Bir LEAD'in sisteme girişinden rezervasyona dönüşme (Won) veya kaybedilme (Lost) sürecine kadar geçen durumları.

stateDiagram-v2 state "Yeni Talep (New Lead)" as NewLead state "Görüşüldü (Contacted)" as Contacted state "Teklif İletildi (Proposal Sent)" as ProposalSent state "Müzakere (Negotiation)" as Negotiation state "Opsiyonlandı (Optioned / Pre-booking)" as Optioned state "Kazanıldı (Won / Reservation Active)" as Won state "Kaybedildi (Lost)" as Lost [*] --> NewLead : Web Form, Instagram, Telefon, Kapıdan NewLead --> Contacted : Satış temsilcisi aradı/görüştü Contacted --> ProposalSent : Teklif (Proposal/Quote) hazırlandı & iletildi ProposalSent --> Negotiation : Müşteri revize veya indirim istedi Negotiation --> ProposalSent : Yeni revize teklif gönderildi ProposalSent --> Optioned : Teklif onaylandı, takvime opsiyon atıldı Optioned --> Won : Kapora (Deposit) alındı, Sözleşme imzalandı %% Negatif Akışlar (Lost Pipeline) NewLead --> Lost : Ulaşılamadı / Yanlış Numara Contacted --> Lost : Bütçe Uymadı / Salon Beğenilmedi ProposalSent --> Lost : Rakip Salon Tercih Edildi Negotiation --> Lost : Fiyat Anlaşmazlığı Optioned --> Lost : Opsiyon Süresi Doldu / Ödeme Gelmedi Won --> [*] : Core Reservation Akışına Devredilir Lost --> [*]

3. Document Generation & Client Portal Sequence

Word şablonundan PDF (Sözleşme/Teklif) üretme (Document Engine) ve bunu Client Portal üzerinden müşteriye güvenli bir linkle sunma sürecinin mimari etkileşimi.

sequenceDiagram autonumber actor Rep as Sales Rep participant UI as SvelteKit (Admin) participant API as FastAPI Backend participant DocEng as Document Engine (LibreOffice / Headless) participant DB as PostgreSQL actor Client as Müşteri (Customer) participant Portal as SvelteKit (Client Portal) %% Document Generation Phase Rep->>UI: "PDF Sözleşme Üret" Butonuna Basar UI->>API: POST /api/v1/docs/generate (Payload: template_id, reservation_id) API->>DB: Fetch Reservation, Customer, and Finance Data API->>DocEng: Inject DB data into Word (.docx) Template variables (e.g. {{customer.full_name}}) DocEng-->>API: Convert to PDF and return File Buffer / S3 Link API->>DB: INSERT INTO generated_documents (pdf_url) API-->>UI: Document Generation Success (Returns PDF Link) %% Portal Link Generation Rep->>UI: "Müşteriye Gönder (Portal Link)" Tıklar UI->>API: POST /api/v1/portal/send-link (Payload: reservation_id) API->>DB: UPSERT portal_access (Generate access_token) API->>Client: Send SMS (Webhook/Provider): "Sözleşmeniz ve formunuz hazır: eventra.app/p/XYZ" %% Client Interaction Phase Client->>Portal: Telefonda eventra.app/p/XYZ linkini açar Portal->>API: GET /api/v1/portal/XYZ/details API-->>Portal: Return Event details, Forms, and PDF Document link Client->>Portal: Kendi eksik bilgilerini doldurur & Sözleşmeyi görüntüler Portal->>API: PUT /api/v1/portal/XYZ/update (Payload: Form Data) API->>DB: Müşteri bilgilerini ve Reservation notlarını günceller API->>DB: Update portal_access audit_logs (Log: "Client viewed contract") API-->>Portal: HTTP 200 OK (Success)
